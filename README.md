# Nap

[nap.cx](https://nap.cx) is the website for Nap, a native Mac interface for coding agents.

The `hexinspo` branch is a minimal dark landing page with a small interactive Nap ghost, a direct macOS download, and a link to the production blog. No forms, database, or external fonts.

Run `npm ci`, then `npm run dev -- --port 3000`. Use `npm run build` to verify the production build.
